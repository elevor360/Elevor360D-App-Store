Elevor360D Spreadshop integration

Added shop.html and a Shop link/button to index.html. All other files are unchanged.

Upload the contents of Elevor360D-App-Store-main to your GitHub Pages repository root (do not add the enclosing folder).

Shop URL: https://elevor360d-shop.myspreadshop.net/
Embedded shop uses official Spreadshop JavaScript integration. Check on published HTTPS website, not local file:// preview.

If the embed does not load, open Spreadshop partner settings > Advanced > Embed Shop in Website, copy the shop-specific integration snippet and verify the shopName / prefix against shop.html.

Products must be published in Spreadshop to appear. Checkout is managed by Spreadshop.
