ELEVOR360D TRAVEL BLOG V1

2. Open https://elevor360d.co.uk/travel-blog.html and test the three sample articles.
3. Open Elevor360D_Blog_Manager_V1.html LOCALLY on your computer (do not publish this manager).
4. Edit/add articles, click Save article, then Export blog-posts.json.
5. Upload the new blog-posts.json to the ROOT of your GitHub website repository, replacing the previous file.
6. Upload any new images into the existing images folder and enter their path in the manager.
7. The existing Travelpayouts Drive script from index.html was copied to the blog listing and article pages. Verify operation and eligibility in the Travelpayouts dashboard; the script may not display offers on every article.
8. Back up the manager articles using Backup articles. Browser storage can be cleared. Import backup restores saved articles.
9. IMPORTANT: Remove Elevor360D_Blog_Manager_V1.html from the GitHub upload: it is an offline editing tool and should not be published.
10. Affiliate disclosure is included; review your privacy/cookie policies for third-party tracking before launch.
