Elevor360D Google Sitemap V3

Includes 20 main HTML pages and 3 static blog article pages.

IMPORTANT: The supplied blog-posts.json contains only 3 starter articles. If you published additional articles on GitHub, download the live blog-posts.json before replacing it. This ZIP would otherwise overwrite your additional posts.

This ZIP is based on the uploaded V2 website. It preserves CNAME, Drive and existing site files.

After deploying, check https://elevor360d.co.uk/sitemap.xml and submit sitemap.xml in Google Search Console > Sitemaps.

When you publish more posts through Blog Manager V2, they will still display via travel-article.html?id=... but won't automatically get a static SEO page or sitemap entry. To upgrade that publishing process, supply Blog Manager V2 HTML for an updated exporter.

Google indexing is not guaranteed.
