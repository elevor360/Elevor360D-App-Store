LOCAL DEALS MULTI-TOWN SETUP

1. Upload all files from the updated website ZIP to your EXISTING website repository, preserving its structure and CNAME.
2. Open Elevore360D-Local-Deals-Multi-Town-Manager-V2.html locally on the same browser where you used the old manager. Your original browser data is migrated to Fleetwood on first opening; back up first.
3. Open Manage Towns, select Fleetwood or Blackpool, enter the published GitHub Pages URL for each town, and set Published.
4. Edit businesses, settings and adverts for the selected town. Download its three JSON files in Publish & Backup and upload them to THAT town's customer app repository. Each town needs its own copy/repository of the V4 customer app files, or a separately configured deployment.
5. From Manage Towns, download local-deals-towns.json and upload it to the ROOT of your website repository. The Local Deals page reads it automatically.
6. Save an All Towns Backup regularly. The manager uses local browser storage and DOES NOT publish directly to GitHub.
7. Existing site CNAME, articles, images, shop, and app listings are retained.

NOTE: The Fleetwood and Blackpool URLs are intentionally blank until you supply live links. No unpublished pages are advertised.
